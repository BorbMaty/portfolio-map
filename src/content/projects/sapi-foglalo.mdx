A university project built by a team of three, supervised by Dr. Zoltán Szántó.

## Problem

Booking a room at our university for anything outside the timetable, such as a university event, meant writing a
paper request for every booking and handing it in. It was slow, nobody could see which rooms were already taken, and
mistakes such as two bookings for the same slot were easy to make.

## What I built

A web app that replaces the paper. After logging in, you see the floor plan of the building: bookable rooms stand out in a
wood texture, the rest (offices, the library, the buffet) are greyed out. Pick a room, choose a date, and the app lists
that day's booked slots in red and suggests free two-hour slots in green. Your own bookings are in one list, each with a
delete button.

There is no sign-up on purpose: only trusted users can book, so accounts are added directly to the database.

## Architecture

The backend is a FastAPI REST API in Python. SQLAlchemy maps the tables to Python objects, a data-access class per entity
(users, rooms, reservations, positions, passwords) keeps the database code in one layer, and Pydantic models validate
everything that crosses the API. The data lives in a MySQL database on Azure. The frontend is plain HTML, CSS and
JavaScript.

We worked through GitHub pull requests, so every change was reviewed before it reached the main branch, and planned the
work on a Kanban board.
